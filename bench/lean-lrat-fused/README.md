# Experimental fused LRAT checker

Pinned to Lean 4.27.0-nightly-2025-12-01. This is an explicit bench prototype,
not an engine default, a GPU implementation or a measured speedup.

## Mechanism and guarantee

Std's checker converts an action array to a list, maps conversion across that
list, filters malformed actions and invalid RAT pivots, then checks the result.
FusedLRAT combines conversion/filtering and sequential checking in one traversal.
It retains the full certificate string parser, parsed action array, Array.toList,
CNF conversion and stock RUP/RAT formula operations. It does not stream parsing
or batch independent proof steps, and does not change native assignment resets.

The kernel-checked theorems run_eq_native, check_eq_native and
verifyBVExpr_eq_native quantify over all action lists, CNFs and certificate
strings. Native skipped-malformed-action and early-terminal behavior is preserved.
The soundness wrapper uses the existing Std theorem. Controls report matching
native/prototype proof axiom sets, including ofReduceBool/trustCompiler, without
sorryAx. Pure checker equality is not universal resource/diagnostic equivalence.

FusedFrontend provides the direct opt-in tactic bv_decide_fused. It uses native
normalization, reflection, bitblasting, SAT search, certificate compilation and
counterexample reconstruction. It changes the reflected checker and soundness
wrapper. There is no fallback that could hide a failed implementation, no compiled
CNF declaration, and no unsafe meta evaluation. Experimental diagnostic wording
and trace nesting are not promised to match stock byte-for-byte.

## Build and run

Use the matching SDK and an absolute BUILD directory outside the checkout.
From this directory, with the owning aggregate RSS/CPU monitoring in place:

    export PATH="$SDK/bin:$PATH"
    export LEAN_SYSROOT="$SDK"
    export LEAN_PATH="$BUILD"
    mkdir -p "$BUILD"
    lean -o "$BUILD/FusedLRAT.olean" FusedLRAT.lean
    lean -o "$BUILD/FusedFrontend.olean" FusedFrontend.lean
    lean Controls.lean

FalseFused.lean and FalseNative.lean must each exit 1 with the same x=15#4
counterexample. For OriginalFirstNative.lean and OriginalFirstFused.lean, prepend
BUILD to the original lean-mlir Lake import path and use upstream --tstack=400000.
These preserve the first complete original theorem and preceding definitions
from lean-mlir b8c4a771319a044854a4bbb49b8821381ef86ff8,
SSA/Projects/SLLVM/Evaluation/AliveAutoGeneratedCopy.lean.
The fused variant adds only the import and one tactic-token change. Source is
Apache-2.0; upstream attribution is retained.
