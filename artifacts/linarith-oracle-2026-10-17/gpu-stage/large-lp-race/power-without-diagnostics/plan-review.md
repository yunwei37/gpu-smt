# Root self-review
This fixes an actual measurement threat discovered in the source rather than
inventing a new tuning route. Original results stay explicitly instrumented;
same algorithms/numeric binaries/native response contract and resource
boundaries remain. Four small qualification cells distinguish diagnostic
overhead from method effect, then one complete corrected pair tests the full
selected cohort. No claim of zero instrumentation, memory superiority, venue
acceptance, GPU impossibility or globally fastest CPU. No delegated review.
