# Complete fixed-certificate omission diagnostic

This report is a self-review by the root thread.

## Question and protocol

The complete own-clock profile leaves an optimistic 2.67957x sensitivity when
exported numerical work is removed. A failed GPU integration cannot resolve
that opportunity. This control returns previously observed coefficients while
Lean still elaborates the source, constructs proofs and checks them.

The control knows the answers in advance. It is neither a deployable oracle
nor evidence of an ordinary cache contribution. All 16,015 source-identified
request keys have consistent coefficient answers. The data and source snapshot
are retained. Verification verdicts and old timing counters are never replayed.

All conditions retain the same 1,000 original sources, eight-item waves, at
most eight candidate tasks, CPUs 0–3, and the 48 GiB address-space limit.
Whole time includes root preparation, queueing, native work and final retirement.
The fresh native cell is this sequence's reference. Older 1,237.37, 1,072.37
and 2,234.69 second observations are separate epochs.

## Interpretation

The AST omission control exceeds 1.5x while retaining Lean checking. Therefore,
the present evidence does not support closing GPU research with a claim that
removing numerical search cannot reach 1.5x. It does not demonstrate that an
implementable GPU solver can deliver 1.59976x.

The matched fresh native target at 1.5x is 818.669012441 seconds, only
51.049902850 seconds above this AST control. This indicates little room for
remaining search, transfer and scheduling costs. It is not a measured GPU
budget or a universal bound: different searches or certificates can change
the execution schedule.

The 1.41664x native-only control does not bound the AST/GPU mechanism, which
also changes Lean-side work. Conversely, the answer-aware 1.59976x control
cannot count toward the best valid CPU/GPU continuation result. Setup, lookup
and IPC remain, so neither observation is a strict zero-cost upper bound.
These are single observations through eight-item waves. The separately
admitted full native eight-queue comparison may strengthen the common baseline.
