## Complete-matrix behavior

analyze.py --stage full independently joins the original29,750source set
against source-ids.json. It looks for all six declared terminals. Running
cells are not read as finished rows. Failed terminals remain visible with
their actual error/retirement records; no partial prefix replaces a complete
cell. All-cells ratio-of-sums appears only when every declared terminal is
complete. It does not auto-certify transparent outcomes or close an RQ.

The all-closed-cell CSV retains every source in each complete cell, even when
its partner has not finished. The paired CSV retains every matched original,
including rejected/incomplete/timeout/resource outcomes. Native outcomes,
recorded resource-mapped statuses, original SDKstatuses, raw messages,
non-message fields and non-timing SDKpayload/error differences stay separate.
Observed clock ratios are emitted alongside differences, without presenting
changed proof outcomes as validated transparent speedup.

HTTPenvelopes span first request through last recorded response, including
retry gaps. HTTP200is not acceptance; missing network ends remain censored,
not zero or silently removed. Unanswered trace requests make actual HTTP
concurrency unavailable rather than inflating it from unmatched log entries. Final HTTP200payloads are compared with the
returned SDKrow. Whole clocks still charge SDKpredispatch waiting and native/
backend retirement. Same-native-ranked1%/10%tails retain the same IDs and all
failure outcomes. Missing native latency coverage makes full-population tail
ranking unavailable. Concurrent sums remain nonadditive wall/CPU quantities.

Resource analysis streams owned-tree RSS, sample gaps, actual native address
limits, over-threshold samples, PID/birth/source kill notices, monitor errors
and largest-native selection. It reports observed overshoot rather than
turning a one-second watchdog into a kernel-hard quota. Native EOFdiagnostics
are counted separately from exhaustive child-exit accounting, which they are
not. No source shapes or partial waited-child CPU become an all-LP GPUbound.
