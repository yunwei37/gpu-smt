## Hypothesis and decision
Actual selected-source native profiles expose product-proof generation after the numeric oracle is accelerated. Positive whole-source effect would justify including the optimized CPU path before any GPU superiority claim. A negative effect closes this optimization; it does not challenge all GPU work or replace the paper's RQs. This differs from upstream FarkasFast parent selection: it changes theorem-application construction, not hypothesis selection.
