## Decision

**No inspected release is yet admitted as a complete, replayable, originally ordered multi-context Lean plus multi-project Verus stream.** This is an acquisition/capture gap, not evidence that real workloads lack sharing. The strongest concrete released *actual attempts* are AutoVerus intermediates, but they are algorithm benchmarks rather than VeruSAGE repository projects, and native call completeness/order needs reconstruction. The strongest Lean capture alternatives are official Goedel evaluation and DeepSeek V1.5 search drivers, with additional boundary logging. DSP+ provides another frozen Mathlib context and intermediate pipeline. VeruSAGE provides source-grounded multi-project tasks for actual fresh capture, not already-released attempts. Do not substitute successful-proof traffic or shuffled benchmark tasks for real candidate streams.

## Concrete accepted-context and toolchain identities

Goedel and DeepSeek V1.5 both contain Mathlib gitlink `2f65ba7f1a9144b20c8e7358513548e317d26de1`; its raw `lean-toolchain` is **Lean v4.9.0-rc1**. These are two policies on one prepared library context, not two independent versions. DSP+ contains Mathlib gitlink `8b97781329503c0db6fac7ff45b0405f83eb47c9`, raw toolchain **Lean v4.17.0-rc1**. These old environments do not automatically admit stock Lean 4.32 disk snapshots; upgrading is a separately validated experiment and can change candidates/decisions. Within each version, stratify by actual imports, prior commands/local declarations, theorem or subgoal prefix and options; broad `import Mathlib` rows alone do not prove useful multi-context placement.

AutoVerus artifact README pins Verus **33269ac6a0ea33a08109eefe5016c1fdd0ce9fbd**, distinct from the canonical current VeruSAGE recommendation **ddc66116aa7a844a9e19cc50922fe85c84b8b4a5**. Do not replay historical AutoVerus files with the modern VeruSAGE pin and label mismatches mechanism failures. Resolve Z3 from each pinned build recipe and record its binary hash/options. `.rs` comments are historical labels, not independently verified native outcomes.
