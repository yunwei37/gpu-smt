## Fairness, uncertainty and paper interpretation

The unchanged pinned source CLI is a valid behavior reference, independently engaging the official frontend on original bytes. It is not a competing performance service. Fresh/split/history/cancellation paths are controls around the tested branch mechanism, not five SOTA baselines. Same native budgets, sequential children, one recorded affinity core and alternating whole-condition order make response parity interpretable. Affinity does not establish exclusive core isolation: load before is1.39/1.83/1.69 and after2.09/2.12/1.85. No superiority claim should be extracted from timings.

The corpus is 156 selected captured native streams/440 checks from published-task execution, not complete historical agent traffic; two preparation groups contain106 and50 streams. Prefixes are9,464 and30 bytes, with no verification in preparation. This qualifies parser/context reuse but does not establish substantial costly preparation sharing. Three consistent repetitions are local repeatability rather than statistical workload generalization. The source timer atfork handling and one-task refusal guard constrain the actual path, not arbitrary Z3 fork safety. Sequential lifetimes do not measure concurrent memory density, admission control, service throughput/tails, fleet PSS or equal-resource superiority. Parent CPU and wall intervals differ; RSS totals and raw smaps are diagnostic only.

A positive result supplies previously absent native EOF/fork/order/disposal observations and removes one concrete RQ2 reject argument for this narrow adapter.
