Freed counts are cumulative recycling, not resident memory or unique objects. This shows the old allocator was retaining recoverable dead state; it also shows reclamation did not resolve the expensive computation.

The algorithm clears weak completed memo entries and rebuilds live intern tables at each collection. Scanning/rebuilding/recomputation plus the newly reachable long reductions are plausible costs. The aggregate timers do not separate those effects, so we do not attribute all1,049.5host seconds to GC alone. Many formerly capacity-limited bodies now hit the unchanged computation limit.
