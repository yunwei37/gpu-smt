# Source-native simp_all phase diagnostic prototype

The23dominant timeouts do not yet show whether one simplification call grows,
the full hypothesis/target context repeats, or discharging dominates. Preserve
the pinned native algorithm in an opt-in namespace and instrument initialization,
individual hypothesis passes and target passes with monotonic costs/rounds/
entry counts and type hashes. No native replacement or active-source rewrite.
No hash/keyword-based rejection. Development compile +6native/profile control
pairs under combined48GiB watch,CPU11,AS uncapped. Retain failed firstcompile.
Only development controls,not a second original-population collection.

A reliable cycle witness needs the full deterministic transition state,
including context/proofs,mvars,cache,options,simprocs and enclosing fallback.
Hash recurrence is not that witness. Rejection remains disabled until such
semantics and actual original-source coverage are established. This is an
implementation step toward measuring that missing evidence,not a novelty claim.
